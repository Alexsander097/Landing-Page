# GV Móveis Sob Medida

Landing page da GV Móveis para apresentar móveis sob medida e facilitar pedidos de orçamento pelo WhatsApp.

## Prévia

| Desktop | Celular |
| --- | --- |
| ![Página inicial em desktop](Img/desktop.png) | ![Página inicial em celular](Img/mobile.png) |

## Recursos

- Páginas Home, Sobre Nós e Contato.
- Layout responsivo para desktop e celular.
- Formulário de contato que prepara uma mensagem de orçamento no WhatsApp.
- Transições entre páginas com suporte à preferência por movimento reduzido.

## Tecnologias

HTML, CSS e JavaScript puro.

## Como visualizar

Clone o repositório e abra o arquivo `index.html` no navegador. Não é necessário instalar dependências ou executar um processo de build.
